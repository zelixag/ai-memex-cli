# Vault Protocol

Use this reference when you need to **locate** a vault, decide whether a path belongs to ai-memex, or understand the high-level layout. **Schema details (page types, frontmatter rules, lint rules) are not duplicated here** — they live in the vault's own `AGENTS.md`, which the relevant CLI commands inline into sub-agent prompts when needed (see "Management vs Use" in `SKILL.md`).

## Vault Roots

The default global vault is:

```text
~/.llmwiki/
```

A project may also have a local vault:

```text
<project>/.llmwiki/local/
```

The local vault is a **disposable, read-only projection** generated by `memex glob`. Durable wiki writes always go to the global vault — never to `local/`. See "Local Vault" in the vault's `AGENTS.md`.

When unsure where the vault lives, run:

```bash
memex status
```

This prints the active vault path and a digest of scenes / page counts.

## High-level Layout

```text
~/.llmwiki/
  raw/         # immutable source documents (CLI never writes here from ingest)
  wiki/        # agent-authored knowledge pages (the compounding artifact)
  AGENTS.md    # vault schema — single source of truth for page types, frontmatter, scene rules
  index.md     # navigable map of the wiki
  log.md       # append-only operation history
```

## Loading the Live Schema

When you need the actual schema rules — page types, frontmatter requirements, scene conventions, lint policies — read the vault's `AGENTS.md` directly:

```bash
cat ~/.llmwiki/AGENTS.md
```

Or rely on management CLI commands (`memex ingest`, `memex lint --with-semantic`, etc.) which spawn a sub-agent and inline `AGENTS.md` into the prompt automatically. **Do not duplicate schema rules in this file** — that copy will go stale; the vault's `AGENTS.md` is authoritative.
